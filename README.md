# RynRoutine v1.0.0 

The first public release of **RynRoutine** — a simple desktop application for organizing your weekly routine.

### Features
- Weekly routine planning (Sunday–Saturday)
- Individual daily schedules
- Custom activities with start and end times
- Light and dark themes
- Local data persistence
- Windows desktop application

### Installation
1. Download `RynRoutine-Setup-1.0.0-x64.exe` from the Assets section.
2. Run the installer.
3. Follow the installation instructions.
4. Launch RynRoutine.

**Platform:** Windows 10/11 (64-bit)
